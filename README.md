# 📍 Интерактивный гид по Нижнему Новгороду

> Учебный проект по дисциплине **«Технологии программирования» (НИУ ВШЭ)**.  
> Интерактивная карта атмосферных, небанальных локаций и фотоспотов Нижнего Новгорода со встроенными рекомендациями заведений поблизости.

---

## 👥 Команда проекта и зоны ответственности

| № | Роль | Ветка в Git | Обязанности |
|---|------|-------------|-------------|
| 1 | **Тимлид / Архитектор** | `main` / `feature/project-setup` | Архитектура, сборка скелета (Vite + React + Tailwind), код-ревью, мерж PR |
| 2 | **Разработчик карты (Map Dev)** | `feature/map-view` | Интеграция Leaflet, кастомные маркеры, попапы, анимации `flyTo` |
| 3 | **UI / Верстальщик карточек** | `feature/place-cards` | Верстка карточек мест, фотогалерея, блок «Где поесть рядом», модальные окна |
| 4 | **Логика, фильтры и поиск** | `feature/filters-logic` | Живой поиск по названию/описанию, фильтры по категориям, подборки маршрутов |
| 5 | **Контент & Данные** | `feature/places-dataset` | Сбор 25–30 локаций, точные геокоординаты, описания и `places.json` |
| 6 | **Девопс / Документация (QA)** | `feature/deploy-and-docs` | Деплой проекта (Vercel), тестирование, мобильная адаптация, README |

---

## 🛠 Технологический стек

- **Frontend:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Картография:** [Leaflet](https://leafletjs.com/) + [React-Leaflet](https://react-leaflet.js.org/) + [OpenStreetMap](https://www.openstreetmap.org/)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
- **Иконки:** [Lucide React](https://lucide.dev/)
- **Данные:** Локальный структурированный датасет `src/data/places.json`

## 🚀 Быстрый старт (Инструкция для разработчиков)

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваша-организация-или-логин>/<имя-репозитория>.git
cd <имя-репозитория>
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере: `http://localhost:5173`

### 4. Сборка для продакшена
```bash
npm run build
```

## 🌿 Регламент работы с Git (Правила команды)

1. **Никаких прямых коммитов в `main`!**
2. Каждый разработчик работает строго в своей ветке:
   ```bash
   git checkout -b feature/<ваша-фича>
   ```
3. Перед началом работы всегда подтягивайте актуальный код из `main`:
   ```bash
   git checkout main
   git pull origin main
   git checkout feature/<ваша-фича>
   git merge main
   ```
4. Фиксация изменений:
   ```bash
   git add .
   git commit -m "feat(map): добавил кастомный попап с фото"
   git push origin feature/<ваша-фича>
   ```
5. Сдача работы: открывается **Pull Request (PR)** в ветку `main`. Тимлид проводит код-ревью и выполняет мерж.

## 📂 Структура проекта

```text
├── src/
│   ├── components/         # Модульные компоненты
│   │   ├── Header.jsx      # Шапка сайта
│   │   ├── Sidebar.jsx     # Боковая панель (поиск + карточки)
│   │   ├── FilterTabs.jsx  # Фильтры по категориям
│   │   ├── PlaceCard.jsx   # Карточка локации
│   │   └── MapView.jsx     # Интерактивная карта Leaflet
│   ├── data/
│   │   └── places.json     # База данных локаций Нижнего Новгорода
│   ├── App.jsx             # Главный контейнер (Split Screen)
│   ├── index.css           # Tailwind CSS и стили скроллбаров
│   └── main.jsx            # Точка входа React
├── index.html              # HTML-шаблон с подключением Leaflet
├── package.json            # Зависимости и скрипты
├── tailwind.config.js      # Конфигурация стилей
└── vite.config.js          # Конфигурация сборщика Vite
```
