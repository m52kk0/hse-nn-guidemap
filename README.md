## О проекте

Приложение помогает найти интересные локации Нижнего Новгорода — от исторических зданий и смотровых площадок до стрит-арта и закатных спотов. Для каждого места можно посмотреть описание, фотографии, точный адрес на карте и список хороших кафе рядом.

### Основные возможности
- **Интерактивная карта**: маркеры локаций с разделением по категориям, центрирование при выборе и ограничение области карты чертой Нижнего Новгорода.
- **База из 28 мест**: реальные координаты, описания, фото и распределение по 8 районам города.
- **3 пешеходных маршрута**:
  - «Исторический Нижний: От Кремля к Покровке»
  - «Закаты над Стрелкой и Набережная Федоровского»
  - «Индустриальная романтика и Заречная часть»
- **«Где поесть рядом»**: список проверенных кафе и ресторанов около выбранного места с примерным чеком и кухней.
- **Поиск и фильтры**: поиск по названию/описанию, выборка по районам (Нижегородский, Канавинский и др.) и категориям.
- **Отметки посещений**: можно отмечать пройденные места (сохраняются в памяти браузера через `localStorage`).
- **Адаптация под телефоны**: переключение между картой и списком на смартфонах, удобная шторка карточки снизу (bottom sheet).

## Технологический стек

- **Фреймворк:** React 18, Vite 6
- **Карта:** Leaflet 1.9, React-Leaflet 4, OpenStreetMap
- **Стили:** Tailwind CSS 3
- **Иконки:** Lucide React
- **Данные:** Локальный JSON-файл `src/data/places.json`, сохранение отметок в `localStorage`
- **Хостинг и CI/CD:** GitHub Actions + GitHub Pages

## Запуск проекта

### 1. Клонирование и установка
```bash
git clone https://github.com/m52kk0/hse-nn-guidemap.git
cd hse-nn-guidemap
npm install
```

### 2. Запуск для разработки
```bash
npm run dev
```
Открыть в браузере: `http://localhost:5173`

### 3. Сборка проекта
```bash
npm run build
```
Собранные файлы появятся в папке `dist/`.
